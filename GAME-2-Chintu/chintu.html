What is this and how does AI play a part?

This is Game 2: Chintu, a running and jumping game written by Claude Code (an AI coding agent) as one HTML file with plain JavaScript. Chintu and everything around him are drawn with code, with no image files. This first version is Phase 1 of the development plan: a test run that checks the running, jumping and sliding. You don't need any AI to play.

How to play

  • Chintu runs by himself and gets a little faster as he goes. You only jump and slide.
  • Jump: Space, ↑ or W (the JUMP button on phones). Hold it to jump higher, or tap it for a small hop.
  • Slide: ↓ or S (the SLIDE button on phones) to get under low roofs. In the air, it makes Chintu drop faster.
  • Bump the ? blocks from below. In Phase 2 they will have laddoo coins inside.
  • Falling into a gap starts the run again. Hearts and checkpoint flags come in Phase 2.
