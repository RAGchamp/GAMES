    How this game was made and how AI plays a part?

    Claude Code, an AI coding agent, read an open-source JavaScript racing example and rebuilt its pseudo-3D road engine in this one HTML file. It fixed the original's bugs, redrew every car, tree and sign with canvas code (there are no image files) and turned the drive into a full game: 3 tracks (one at night), 3 modes, rain, touch controls and a top-5 leaderboard. Every sound (engine, tyres, crashes, coins) is synthesised by the browser, so there are no sound files either. You don't need any AI to play. See the plan →
