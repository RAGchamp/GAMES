AI Games Portal

How these games were made and how AI plays a part?

Every game here is one HTML file with plain JavaScript: no frameworks, no image files, no sound files and no server. Claude Code, an AI coding agent, takes a small open-source example, reads and understands it, fixes its bugs and builds it into a full game in planned phases, testing each phase in a real browser as it goes. All the art is drawn with canvas code and all the sound is generated by the browser. PLEASE NOTE: You don't need any AI to play. The AI is used only to write the code.

🤖How AI turned a 350-line demo into a full game
1
Read the original
An open-source JavaScript racer: a smooth road engine, but no race, no score and no game over. The AI listed its 10 bugs and gaps.
2
Plan in phases
A written plan with goals, a feature list and a "done when" test for every phase, agreed before any code was written.
3
Build and redraw
The engine was rebuilt, every car and tree redrawn in code, and rivals, sound, pickups, tracks, modes, touch controls, a coaching driver and video recording added.
4
Test like a player
Each phase was played in a real browser by test scripts that clicked, steered and raced, took screenshots and checked for errors before moving on.
